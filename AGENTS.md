# Repository instructions

- This is a pnpm workspace (`packages/*`) with three runtime packages: `remote-userscript` owns in-page control, `remote-extension` is the Chromium MV3 client, and `cdp-bridge` owns the Node.js HTTP/CDP WebSocket server. Keep page control out of the bridge and transport/lifecycle logic out of page clients.
- Use Node.js 20+ and pnpm. Run `pnpm check`, `pnpm build`, then `pnpm --filter @remote-page-agent/cdp-bridge test`; the release workflow runs check before build. A focused test can be selected with `node --test packages/cdp-bridge/test/cdp-session.test.mjs --test-name-pattern='pattern'` after building.
- `packages/*/dist` is generated and ignored. Never edit generated userscript or extension output: `pnpm build` injects the userscript package version and creates `packages/remote-extension/dist/remote-page-agent-extension-v<version>.zip`.
- Keep `packages/remote-userscript`, `packages/cdp-bridge`, and `packages/remote-extension` versions aligned before a release. `cdp-bridge/src/index.ts` reports its package version in `Browser.getVersion`; the userscript build injects its own version, and the extension package script uses its package version for the ZIP name while `extension/manifest.json` must be updated manually.
- Preserve JSON request/response ID correlation and structured `{ ok: false, error: ... }` failures. Prefer fixed DOM commands and the existing restricted evaluation allowlist; do not add arbitrary evaluation, secret/cookie extraction, or site-specific selectors.
- Preserve logical page IDs, duplicate-target protection, reconnect grace handling, target/session lifecycle events, and response-before-navigation behavior for clicks and inputs.
- The bridge defaults to `127.0.0.1:9222`. Configure `REMOTE_AGENT_TOKEN`, `REMOTE_AGENT_CONNECTION_WINDOW_MS`, and `REMOTE_AGENT_MAX_CONNECTION_ATTEMPTS` via environment or `.env` (`.env.example` documents them); never expose an unauthenticated bridge to an untrusted network.
- Formatting and type checks use Biome plus workspace TypeScript checks through `pnpm check`; `biome.json` excludes generated `dist` files.
- Pushing a `v*` tag triggers `.github/workflows/release.yml`, which installs with `--frozen-lockfile`, checks, builds, uploads the userscript/bridge archive and extension ZIP, and creates a GitHub Release. Confirm the tag does not already exist before tagging.
- Update `docs/message-protocol.md` when protocol behavior changes; consult `docs/implementation-plan.md` and `docs/userscript-to-extension.md` for migration constraints.
